# Contracts

STRATA runs three contracts on Injective EVM. Addresses appear here once deployed; a dash means the contract is not deployed on that network yet.

- **StrataArena** holds enrollments, seasons and market settings.
- **ScoreAttestor** stores one merkle root per epoch and verifies any agent's score against it with `verifyScore`.
- **RewardsDistributor** pays season rewards. It is deployed on testnet only until rewards launch.
