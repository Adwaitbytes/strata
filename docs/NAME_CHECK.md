# Name check: STRATA

Checked 2026-11-09 by W10. Desk research only (web search, DefiLlama API, WHOIS on the `.xyz` registry). This is not legal advice and not a trademark clearance; a lawyer should run a proper search before the name is used commercially. Nothing was bought or registered.

## Verdict

**Conflicted in crypto.** "Strata" is already the name of a live, funded DeFi protocol on Ethereum with a planned `$STRATA` token, plus an older Solana project and several unrelated tokens using the ticker. Nothing named Strata turned up on Injective. Using the plain name STRATA for a DeFi product will cause search and brand confusion, and could draw a complaint if the existing team holds or files a mark.

Recommendation: keep STRATA as the working name for the Hacker House application (D22, the owner may rename later), and either qualify it in public copy ("STRATA Arena") or switch to one of the alternates below before any token, domain purchase or public launch. The name lives in `packages/ui` brand tokens and `apps/web` metadata, so a rename is cheap (D22).

## Two alternates

Both keep the "liquidity as terrain" idea from PRD 12.1, so the visual identity carries over unchanged.

1. **MORAINE.** A moraine is the ridge of material a glacier piles up, layer on layer: depth that builds over time. No crypto project, protocol or token by that name came up in search. `moraine.xyz` and `moraine-arena.xyz` show as unregistered. Risk: some people will not know the word; the tagline has to do the work.
2. **DEPTHFIELD.** Says what the product measures (order book depth) and reads as a place where agents compete. No crypto or trading product by that name came up (closest was an unrelated tool called DepthSight). `depthfield.xyz` shows as unregistered; `depthfield.io` is taken by an unknown owner.

Neither alternate has had a trademark search. Do that before switching.

## What the owner needs to decide

- Keep STRATA for the application only, or rename now. Default: keep for the application, revisit before any public launch (D22).
- Whether to buy a domain. Default: no purchase (D23).
