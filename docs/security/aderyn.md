Result: **0 High, 0 Medium, 1 Low (accepted).**

- **L-1 Centralization Risk (accepted).** Owner-only functions on StrataArena (seasons, markets, caps, suspension, attestor) and RewardsDistributor (configure, fund, sweep) are by design (PRD 8.1, 8.3). Mitigations: Ownable2Step, `renounceOwnership` disabled, no upgradeability, no native funds held, rewards roots write-once, sweeps blocked until the 30-day claim window ends. Mainnet owner must be a Safe that differs from the attestor; Deploy.s.sol enforces both (W11 I-3).

Resolved in code:
- Reentrancy (state change after external call) in `RewardsDistributor.fund`: effects before interactions; reverts `UnsupportedToken` unless exactly `amount` arrives.
- `nonReentrant` not first modifier: reordered on `fund` and `sweep`.
- Large numeric literal: `10_000` written as `1e4`.

Marked false positive inline (`aderyn-fp-next-line(reentrancy-state-change)`), reasons in code comments:
- `StrataArena.enroll` calls `IERC721.ownerOf`; `ScoreAttestor.postEpoch` calls `IStrataArena.attestor()`, `currentSeason()` and `seasons()`. All are declared `view`, so Solidity emits STATICCALL: the callee cannot write state or reenter. The arena address in ScoreAttestor is immutable.
